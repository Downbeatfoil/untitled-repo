# Demo script (aim for 2 minutes)

1. **Hook (15s):** the problem, in one sentence a judge feels.
2. **Live demo (75s):** follow the demo path in `docs/IDEA.md`. Pre-fill inputs. Have a backup recording.
3. **How (20s):** Grok + how it was built (agent swarm, board PR, show the comment count).
4. **Ask/close (10s):** which track(s) it fits and why.

Backup plan: if the API is slow or down, the app falls back to mocks automatically (`mocked: true`).
